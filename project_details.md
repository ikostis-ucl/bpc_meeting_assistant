# Meeting Assistant

Access and revisit project meeting records.

## Project details:
* **Use case details**:
  * Structured records of each meeting held for a project over the duration of it.
  * Standardized document layout (per project)
  * Need to access the details of the report and the decisions taken, efficiently.
* **Tentative start period**: September 2024
* **Expected duration for the implementation to finish**: 4-5 months
